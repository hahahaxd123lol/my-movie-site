  * Thread/reply posting RPCs use auth.uid() directly.
  * Broken icon-font squares replaced at runtime with inline SVG icons.
  * Permanent forum Realtime subscriptions removed; visible page refreshes once/30s.
- Public chat:
  * Chat bootstrap now tries the single Supabase RPC first and falls back to Edge only if needed.
  * Sitewide prewarm is cached for 60 seconds per tab/session so /chat/ can paint instantly.
  * Public chat image sending is hidden and rejected by both RPC and Edge paths.
  * Own-message delete no longer requires legacy chat identity readiness.
  * Realtime chat remains enabled on /chat/ itself.
- Login / Create Account:
  * One canonical modal behavior loaded last sitewide.
  * Close X works.
  * Login/Create Account tabs switch correctly and only the active tab is red.
  * Create Account submit works from the modal.
  * Email login uses direct Supabase Auth for speed; username login uses Rapid Worker.
  * Removed old device-wide auth preflight from normal login/signup path so a Site Suspension
    on one account cannot poison every account on the same browser/network.
- Staff moderation:
  * Site Suspension is account-scoped and stored only against the target user_id.
  * Realtime account-enforcement subscription is filtered to the signed-in user_id.
  * Restriction shows one proper blocking popup immediately; no blur-only state.
  * Unticking clears the popup through Realtime without needing a refresh.
  * Fallback enforcement check is once/minute; Realtime is the instant path.
  * Owner -> Staff functions repaired as v159 RPCs.

SUPABASE USAGE REDUCTIONS
- One shared browser Supabase client is reused on the main interactive pages.
- Removed duplicate leaderboard presence heartbeat.
- Removed bulk idle prefetch of up to 12 profile live snapshots; exact hover/touch/focus prefetch remains.
- Leaderboard: 1 RPC every 30s instead of 2 RPCs every 30s.
- Forum: no permanent Realtime subscription; 1 bounded refresh every 30s while visible.
- Moderation: one filtered Realtime subscription for the current account + 60s safety check.
- Announcements: 60s visible-page polling instead of a sitewide Realtime channel.
- Stream controls: 60s polling only while on /watch/.
- Chat prewarm: maximum one bootstrap RPC per 60s per tab session; chat itself uses Realtime.
- User autocomplete: 300ms debounce + 60s prefix cache + minimum 2 characters.

Free-tier note: these changes minimize request/subscription volume while keeping requested realtime
features, but no code can guarantee a free-tier bill under unlimited traffic. The remaining recurring
calls are deliberately bounded and are only active on pages/features that need them.
