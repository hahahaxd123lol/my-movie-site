Staff Control Center

Moderate users and chat, review reports, curate the homepage, manage streaming source availability, answer support tickets and inspect the staff audit trail. Every write is permission-checked in Supabase.

New Staff Quick Guide These controls affect real users and the live site. If you are unsure, use a warning or note before a ban, and write a clear reason so the audit log makes sense later.
Ban

Blocks the signed-in account from using Flix2Watch. Use for serious or repeated abuse. A duration of 0 means permanent until unbanned.

Mute

Stops the user from sending chat messages for a set time, but does not block watching the site.

Warning

Sends a centered warning notice to the user and stores it on their account. Good for a first or less-serious issue.

Support Priority

Low can wait, Normal is standard, High should be handled soon, and Urgent should be looked at first.

Report Status

Open = waiting. Reviewing = a Staff member is handling it. Resolved = action taken. Dismissed = no action needed.

Source Priority

Lower numbers load earlier. Priority 1 is tried before 2, 2 before 3. Disable a source only when it is genuinely broken or unsafe.
