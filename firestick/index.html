Quick setup

How to install it

You can do the whole installation on your Fire TV Stick. No computer or USB cable needed.

1

Get Downloader

Open the Amazon Appstore on your Fire TV, search for Downloader, then install it.

2

Allow app installs

Go to Settings → My Fire TV → Developer Options → Install unknown apps and enable Downloader. If Developer Options is missing, open About and select your device name 7 times.

3

Open this page in Downloader

Enter flix2watch.com/firestick in Downloader's address box and press Go.

4

Press Download, then Install

On this page, press Download for Fire TV. When the APK finishes downloading, choose Install, then Open.
