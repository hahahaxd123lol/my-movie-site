FLIX2WATCH CLEAN URL PACK

Upload EVERYTHING in this pack to the ROOT of your GitHub Pages repository.

Your URLs will become:

https://flix2watch.com/home/
https://flix2watch.com/watch/?id=123&type=movie
https://flix2watch.com/favorites/
https://flix2watch.com/profile/@josh

Opening https://flix2watch.com/ redirects to /home/.

IMPORTANT:
Do not upload the old root watch.html, favorites.html or profile.html after this.
The new pages live inside folders:
home/index.html
watch/index.html
favorites/index.html
profile/index.html

GitHub Pages serves each folder's index.html automatically, so visitors never see
index.html/watch.html/profile.html/favorites.html in the address bar.
